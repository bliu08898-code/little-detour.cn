# LITTLE DETOUR MVP

一个面向旅途中用户的真实地点决策产品：在限定的时间段内，不再纠结，不再困扰，直接根据用户的个人偏好与预算，选择一个此刻确实去得了的地点，并附上一项有点意思的小任务。
